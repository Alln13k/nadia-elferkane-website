# Nadia El Ferkane-Blanc — site indépendant

Site vitrine en français pour Nadia El Ferkane-Blanc, thérapeute familiale systémique à La Ciotat et Marseille.

## Développement

```bash
npm install
npm run dev
```

Production :

```bash
npm run lint
npm run build
npm start
```

Les informations publiées sont issues du site source officiel et des contenus existants validés. Les deux images de
`public/images/` sont les fichiers PNG originaux, copiés sans transformation.
